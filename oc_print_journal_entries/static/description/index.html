WHAT IT DOES

Complete journal entry details in a clean PDF

This module adds a Print Journal Entries option inside the Print menu of any invoice. It generates a professional PDF showing all journal entry lines with Partner, Account, Label, Due Date, Analytic Account, Tax percentage, Debit and Credit columns. You can also select multiple invoices from the list view and print all their journal entries at once.
PRINT MENU

Added to Invoice Print Menu

A new Print Journal Entries option appears in the Print dropdown of every posted invoice alongside Invoice PDF and PDF without Payment.
BULK PRINT

Select Multiple & Print

From the Invoices list view, select multiple records and click Print → Print Journal Entries to generate a combined PDF for all selected invoices at once.
PDF REPORT

Professional PDF Layout

The report shows Journal Entry number, Journal, Date, Reference, and a full table with Partner, Account, Label, Debit and Credit for every line.
FULL DETAIL

All Journal Line Columns

Includes Partner, Account, Label, Due Date, Analytic Account, Taxes (%), Debit amount and Credit amount for every journal entry line.
ACCOUNTING

For Accountants & Auditors

Perfect for internal audits, month-end reviews, and sharing journal entry details with external auditors or management without giving Odoo access.
ZERO CONFIG

Install and Use

Install the module and the Print Journal Entries option appears immediately in the Print menu of every invoice. No configuration needed.

FEATURE 1 — FROM INVOICE FORM

Print Journal Entry from any Invoice

Open any posted invoice, click the Print button, and select Print Journal Entries from the dropdown menu. The journal entry PDF downloads instantly showing all accounting lines for that invoice.

FEATURE 2 — THE PDF REPORT

Clean, professional Journal Entry PDF

The generated PDF displays the Journal Entry number, Journal name, Date, and Reference at the top. Below that is a full table of every journal line showing Partner, Account, Label, Due Date, Analytic Account, Tax %, Debit and Credit columns.

FEATURE 3 — BULK PRINT FROM LIST VIEW

Select multiple invoices and print all at once

In the Invoices list view, tick the checkboxes for multiple invoices, click Print → Print Journal Entries. A single combined PDF is generated containing the journal entries of all selected invoices — perfect for month-end or period-end reporting.

HOW TO USE

Two ways to print journal entries

Method A — Single Invoice

From the invoice form view

1. Open a posted Customer Invoice

2. Click the Print button

3. Select Print Journal Entries

4. PDF downloads instantly

Method B — Multiple Invoices

From the invoice list view

1. Go to Invoicing → Invoices list

2. Tick checkboxes for multiple invoices

3. Click Print → Print Journal Entries

4. Combined PDF for all selected invoices
